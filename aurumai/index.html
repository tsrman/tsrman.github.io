AurumAI documentation

AurumAI is a self-hosted AI chat and agent platform for organizations: chat with models and agents, knowledge bases, skills and tools, multi-agent workflows, and an optional sandboxed agent (Hermes Agent). Start with the section for your role.

I use the platform

  • User guide: sign in, chat, attach documents, knowledge bases, images, workflows, settings.
  • Hermes Agent guide: the agent with its own workspace.

I administer an organization

  • Administrator guide: users and groups, capabilities and grants, models, agents, skills, workflows, knowledge access, usage.
  • Workflows and starter tools.
  • Agent roles.

I install and operate it

  • Installation and deployment: Compose, Helm, proxy and TLS, optional features, production checklist.
  • Operations: health, upgrades, backups, troubleshooting.
  • Configuration reference: every setting.
  • Air-gapped deployment.
  • Data archive, export and restore.

I integrate or review it

  • API reference.
  • Security model.
  • Architecture and the Hermes Agent design.

I contribute

  • Testing and coverage and release preparation.
  • Contributing and the roadmap.

Conventions

Screenshots are of a development installation with the sample accounts. Names of environment variables are given as they appear in .env; the backend reads the same setting with an APP_ prefix. Source code, comments and documentation are in English; the interface itself is available in English and Russian.
